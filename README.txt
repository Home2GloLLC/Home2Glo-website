HOME2GLO CLEANING SERVICES LLC WEBSITE

Files:
- index.html: website homepage
- styles.css: responsive design and styling
- CNAME: custom domain for GitHub Pages
- robots.txt: allows standard search crawlers

Before publishing:
1. Create a PUBLIC GitHub repository named home2glo-website.
2. Upload all four files to the repository root.
3. In Settings > Pages, choose Deploy from a branch, Branch: main, Folder: /(root), then Save.
4. Wait for GitHub Pages to publish. Add home2glollc.com in Settings > Pages > Custom domain.
5. In GoDaddy DNS, set the GitHub Pages records only after the domain is added in GitHub Pages. Do not delete MX/TXT email records.
6. GitHub's current DNS values are listed in the setup instructions shared in chat.

The quote request form opens the visitor's email app and prepares an email to homeglo235@gmail.com. It does not send data to a server.
